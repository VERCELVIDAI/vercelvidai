# Fluvia Flow — AI Creative Platform & Cinema Studio

> **"Your imagination. In motion."**  
> Create cinematic videos, striking visuals, and campaign-ready content with AI — all inside one unified creative studio.

Inspired by the visual density and creative control of platforms like Higgsfield, **Fluvia Flow** empowers creators, brands, and agencies to direct camera trajectories, emulate optical lenses, orchestrate multi-scene storyboards with Google Gemini, and finish videos on a non-linear multi-track timeline.

---

## Key Creative Studios & Features

1. **Cinema Studio (`/studios/cinema`)**:
   - Multi-axis camera motion controls: Static Lock, Dolly In, Dolly Out, Tracking Shot, Orbit 360°, Crane Boom, Handheld Raw, Aerial Drone.
   - Optical lens emulation: 35mm Anamorphic (cyan lens flares), 50mm Prime, 85mm Telephoto, 24mm Ultra-Wide.
   - Color chemistry presets: Kodak 2383 Film Print, Cyberpunk Teal & Orange, Bleach Bypass, Cinematic Noir, Sunset Golden Hour.
   - Live Gemini-assisted prompt enrichment and cinematic director guidance.

2. **Marketing Studio (`/studios/marketing`)**:
   - Turn physical products and concepts into high-converting video commercials, viral UGC hooks, and feature showcases.
   - Integrated with Gemini Marketing Copilot for audience profiling, 3 tested hook angles, and commercial voiceover scripts.

3. **Storyboard Studio (`/studios/storyboard`)**:
   - Multi-shot scene sequencing and pacing with validated structured JSON storyboards powered by Google Gemini.
   - Instant export to the non-linear Creative Canvas timeline editor.

4. **Creative Canvas Editor (`/editor`)**:
   - Multi-track non-linear timeline supporting video tracks, voiceover narration, sound effects, subtitles, and direct export.

5. **Multi-Model Generative Dispatcher**:
   - Fluvia Neural Motion Engine HD, Runway Gen-3 Alpha, Luma Dream Machine Ray, Fal Flux 1.1 Pro Vision, ElevenLabs Voice AI, and Google Gemini 1.5/2.0.

6. **PayU India Payment & Billing**:
   - Full INR hosted checkout, automated GST tax invoices (PDF), payment receipts, and credit ledger accounting.

7. **Theme Personalization System**:
   - 10 dual-mode (Light/Dark) color palettes including Midnight Violet, Ocean Blue, Emerald Luxe, Rose Quartz, Arctic Silver, Royal Indigo, Obsidian Gold, Mint Breeze, Sunset Ember, and Cyber Cyan.

## Local Development Quickstart

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Compile strict production build
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view Fluvia Flow.
